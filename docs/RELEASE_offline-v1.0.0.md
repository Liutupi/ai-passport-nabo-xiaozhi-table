# NABO 牌桌 · 对决 离线版 v1.0.0

发布日期：2026-10-21。标签：`offline-v1.0.0`。这是不带小智的独立离线固件，源码入口为 `standalone/`；小智牌桌版继续使用 `v1.6.0`。

## 功能

- 首页可进入 NABO 牌桌、NABO 对决和设置；牌桌含 21 点、大话骰、谁是卧底。
- 两台 AI Passport 通过 ESP-NOW 直连对决，不需要路由器，也可单人练习。
- 等待声改用原 NABO 木鱼的短敲击，逐渐加快，拔枪前停止新敲击；拔枪保留“叮”，没有循环风声。
- 每局、等待下一局和整场结算均按本机玩家的胜负播放：赢了吹枪，输了哭脸／被呲；抢跑判负也播放失败动画。
- 使用兼容分区进行应用升级，保留设置、成绩、NVS、原资源和文件分区。

## 下载与安装

下载本标签的安装 ZIP，解压后阅读 `README_zh.md`。不要将此离线版当作带小智的固件。

已有兼容 NABO 自定义分区时，每次只接一台，运行 `flash_one.bat`。它核对实时 MAC、ESP32-C3、8 MB Flash、安全状态及分区，完整备份并验证，只写 `0x10000` 的应用，随后回读核对应用及保留区。需要 Python 3.11+ 与 `esptool==5.5.0`；依赖见 ZIP 内 `requirements-flash.txt`。

首次安装可将 `nabo-table-duel-offline-merged.bin` 从 `0x0` 写入。合并镜像包含公开启动器、分区表和应用，会覆盖该范围内的原设置；先备份原固件。应用升级工具发现不兼容分区时会拒绝刷写，不会自动改为完整安装。
